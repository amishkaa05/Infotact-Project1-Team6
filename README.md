# Infotact-Project1-Team6

AtmoSync – IoT Sensor Data Storage & SQL Analysis

📌 Project Overview

AtmoSync is an IoT-based data storage and analysis project designed to monitor environmental conditions during commodity transportation.

The project collects sensor readings such as temperature, humidity, vibration, battery level, sensor status, location, commodity, and transport mode. The sensor data is stored in a MySQL database and analyzed using SQL queries.

The main purpose of this project is to demonstrate how IoT sensor data can be stored, validated, and analyzed using SQL for logistics and commodity monitoring.



🎯 Project Objectives

1 Create a MySQL database for IoT sensor data.
2 Create tables to store sensor readings.
3 Import sensor data from a CSV dataset.
4 Store and manage structured IoT data using MySQL.
5 Validate the stored data using SQL queries.
6 Analyze temperature, humidity, vibration, and battery levels.
7 Analyze commodities and transportation modes.
8 Identify potentially abnormal sensor readings.
9 Generate useful business insights from IoT data.



🛠️ Technologies Used

* MySQL
* MySQL Workbench
* SQL
* CSV Dataset
* IoT Sensor Data

The project uses an IoT sensor dataset containing environmental and transportation-related sensor readings.
